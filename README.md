# 🎲 Masmorra dos Dados

**Um RPG de fantasia sombria com exploração, estratégia e combates decididos pelos dados.**

As ruínas de Aldrath guardam perigos, criaturas e desafios. Escolha sua classe, administre seus recursos e prepare-se para enfrentar a masmorra.

## Sobre o projeto

Masmorra dos Dados é um jogo desenvolvido com HTML, CSS e JavaScript, com estética de fantasia sombria e arte em pixel art.

## Funcionalidades

- Escolha de classes de personagens.
- Combate com mecânicas baseadas em dados.
- Inimigos com diferentes características e ataques.
- Exploração de cenários de fantasia.
- Interface temática com controles de som e cenas.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Pixel art

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Inicie a jornada e escolha sua classe.

## Estrutura do projeto

- `index.html` — estrutura das telas.
- `style.css` — estilos e identidade visual.
- `script.js` — lógica e mecânicas do jogo.
- `pixel.js` — recursos gráficos incorporados.
- `img/` — imagens dos personagens, inimigos e cenários.
